# Contributing to StageHand Starter Kit

Thank you for your interest in contributing!

StageHand Starter Kit aims to help beginners understand voice-controlled workflows, MCP integration, and TouchDesigner.

## Ways to Contribute

You can contribute by:

- Improving setup instructions.
- Adding useful voice-command examples.
- Documenting common errors and solutions.
- Correcting spelling or unclear explanations.
- Adding beginner-friendly tutorials.
- Reporting bugs or suggesting improvements.

## Before Contributing

1. Read the README and relevant documentation.
2. Check whether the issue or improvement has already been reported.
3. Keep changes focused and easy to understand.
4. Never include passwords, API keys, tokens, or private information.

## Making a Contribution

1. Fork the repository.
2. Create a branch for your changes.
3. Make your changes.
4. Review your work for accuracy and clarity.
5. Commit your changes with a descriptive message.
6. Open a pull request describing what you changed and why.

## Documentation Guidelines

- Use clear, beginner-friendly language.
- Include commands and examples where useful.
- Explain assumptions and prerequisites.
- Do not claim that untested instructions have been verified.
- Keep examples consistent with the documented implementation.

## Reporting Issues

When reporting an issue, include:

- A brief description of the problem.
- Steps to reproduce it.
- Expected and actual behaviour.
- Relevant error messages, with sensitive information removed.

## Code of Conduct

Be respectful, constructive, and welcoming to contributors of all experience levels.

Thank you for helping make this project more useful for the community!
